# Portfólio Profissional — Daniel Brum

Portfólio profissional desenvolvido para apresentar meus projetos, habilidades e serviços nas áreas de **desenvolvimento, automação, análise de dados e tecnologia**.

O projeto também representa minha trajetória na integração entre **Engenharia Elétrica e Tecnologia**, utilizando programação e análise de dados para desenvolver soluções práticas para problemas reais.

## 🌐 Sobre o projeto

Este site foi desenvolvido para funcionar como uma apresentação profissional e também como uma vitrine dos serviços que posso oferecer como freelancer.

A proposta é apresentar de forma simples e objetiva:

* 🐍 Automação com Python

* 🗄️ Banco de dados e SQL
* 🌐 Desenvolvimento Web
* ⚙️ Soluções digitais personalizadas
